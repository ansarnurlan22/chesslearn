# ChessCheese: правила проекта
Проект: chesscheese.site, анализ шахматных партий с Lichess и Chess.com (Stockfish в браузере, Supabase Auth и БД). Интерфейс на русском, стиль 8-bit и сыр.

## Как работать
- Делай ТОЛЬКО ту задачу, которую я назвал, затем остановись и дай отчёт.
- Не читай весь репозиторий, открывай только нужные файлы. Правь точечно, не переписывай работающее.
- Не меняй формат данных результата разбора без необходимости. Если меняешь, перечисли изменения.
- Один клиент Supabase на весь проект.
- Секреты (ключи, Client Secret) не пиши в код и не показывай в чате.
- SQL-миграции и настройки продакшна не применяй сам: дай SQL и инструкцию.
- Не задавай вопросов, выбирай разумное решение и пиши его одной строкой.
- Перед завершением проверь результат: запусти проект, через браузерного субагента пройди сценарий и приложи скриншот.

## Эталон для проверки движка
Тестовая партия: JuliusJJ12 vs MagnusCarlsen (PGN лежит в файле tests/magnus.pgn).
Chess.com: точность белых 85.3, чёрных 96.5. Чёрные: 0 зевков, 0 ошибок. Белые: 5 ошибок, 0 зевков, 0 блестящих. Допуски: точность ±5, метки ±2 на категорию.
